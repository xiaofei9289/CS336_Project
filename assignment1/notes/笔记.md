## 一、BPE Tokenizer

### 1. `get_tokenizer()`

```
def get_tokenizer(
    vocab,
    merges,
    special_tokens=None,
):
```

#### 功能

根据已经训练好的：

- `vocab`
- `merges`
- `special_tokens`

创建并返回一个 BPE Tokenizer。

#### 参数

##### `vocab`

```
dict[int, bytes]
```

表示 token ID 到 token 字节的映射，例如：

```
{
    97: b"a",
    98: b"b",
    256: b"ab",
}
```

##### `merges`

表示 BPE 合并规则：

```
[
    (b"a", b"b"),
    (b"ab", b"c"),
]
```

顺序非常重要，前面的规则优先级更高，也表示更早学习到。

##### `special_tokens`

例如：

```
["<|endoftext|>"]
```

这些字符串必须作为完整 token 处理，不能被 BPE 拆开。

#### 返回值

返回你自己实现的 Tokenizer 对象。测试代码之后会调用它的：

```
tokenizer.encode(...)
tokenizer.decode(...)
```

### 2. `run_train_bpe()`

```
def run_train_bpe(
    input_path,
    vocab_size,
    special_tokens,
    **kwargs,
):
```

#### 功能

调用实现的 `train_bpe()`，读取文本语料并训练 BPE 词表。

它和前面学习的 `train_bpe()` 是同一个核心任务。

#### 输入

- `input_path`：训练语料文件路径
- `vocab_size`：最终词表大小，包含特殊 token
- `special_tokens`：需要提前放入词表的特殊 token
- `**kwargs`：额外参数，例如并行进程数量等

#### 训练过程

大致是：

1. 读取语料
2. 使用正则表达式进行预分词
3. 把文本转换成 UTF-8 字节
4. 统计相邻 token pair
5. 找到出现次数最多的 pair
6. 合并这个 pair
7. 把合并结果加入词表
8. 重复直到达到 `vocab_size`

#### 返回值

```
(vocab, merges)
```

其中：

```
vocab: dict[int, bytes]
merges: list[tuple[bytes, bytes]]
```

注意这里的 `merges` 是：

```
字节 pair 列表
```

不是你在 minBPE 中看到的：

```
dict[(left_id, right_id), merged_id]
```

两种格式表达的都是 BPE 合并规则，但数据结构不同。
